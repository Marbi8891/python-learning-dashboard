# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Lo que se espera

- Tratar a todo el mundo con respeto, sea cual sea su nivel: aquí también se viene a aprender.
- Criticar el código y las ideas, nunca a las personas.
- Aceptar las correcciones y pedir perdón cuando uno se equivoca.

## Lo que no se acepta

- Insultos, acoso, comentarios discriminatorios o de carácter sexual.
- Publicar datos privados de otra persona sin su permiso.
- Cualquier conducta que sería inapropiada en un entorno profesional o en clase.

## Cómo avisar

Escribe a **mrabehfathiprofesional@gmail.com** con el asunto «Conducta». El aviso se trata de forma
confidencial. El autor del proyecto puede editar o borrar comentarios, commits o issues que no
cumplan este código, y bloquear a quien lo incumpla de forma repetida.

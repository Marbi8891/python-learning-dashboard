Objeto y actividad

Python Learning Dashboard es una web para aprender Python y preparar el examen PCAP. Todo su contenido es gratuito y no tiene publicidad.

Además, el titular ofrece material de estudio complementario de pago (el «Pack PCAP») y acepta donaciones voluntarias. Ambos se gestionan fuera de esta web, en plataformas de pago externas que muestran sus propias condiciones antes de pagar. Donar no da acceso a funciones adicionales.

El proyecto no está afiliado a Python Institute ni a OpenEDG. PCAP es una marca de sus titulares, y ni el certificado que genera la web ni el Pack PCAP son oficiales.

El código de la web se publica bajo licencia MIT en el repositorio del proyecto. Las explicaciones y preguntas son originales; las fuentes enlazadas pertenecen a sus autores.

El Pack PCAP no está incluido en esa licencia: es para uso personal de quien lo adquiere y no se puede redistribuir ni revender.

El contenido, gratuito o de pago, tiene fines de estudio y se ofrece sin garantía de aprobar el examen. Consulta siempre la información oficial de Python Institute.

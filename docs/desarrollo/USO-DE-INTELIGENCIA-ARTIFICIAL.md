# Uso de inteligencia artificial durante el desarrollo

## 1. Declaración

Durante el desarrollo de Python Learning Dashboard se han utilizado herramientas de inteligencia artificial generativa, entre ellas Claude Code y ChatGPT, como apoyo al trabajo de análisis, programación, depuración, pruebas y documentación.

Este uso se declara expresamente. La IA no se presenta como autora única del proyecto ni se afirma que todo el código haya sido escrito manualmente por el alumno.

La responsabilidad académica y técnica del proyecto corresponde al alumno: debe poder explicar el alcance, las decisiones que ha aceptado, el funcionamiento de las partes relevantes y las comprobaciones realizadas. Esta declaración debe ajustarse a las normas concretas del centro y a la contribución que pueda acreditarse.

## 2. Usos de las herramientas

Las herramientas se pueden haber utilizado para:

- Explorar alternativas de diseño y arquitectura.
- Proponer implementaciones o modificaciones de código.
- Explicar errores y sugerir formas de depuración.
- Proponer casos de prueba y ayudar a interpretar sus resultados.
- Revisar documentación y detectar inconsistencias.
- Preparar esquemas, listas de tareas y material para la defensa.

Esta lista describe categorías de uso, no atribuye automáticamente cada tarea a una herramienta. Para documentar un cambio concreto se debe añadir una entrada al registro de uso.

## 3. Qué decisiones corresponden al alumno

En cada funcionalidad se debe poder identificar:

- Qué necesidad se quería resolver.
- Qué alcance se decidió abordar.
- Qué alternativa se eligió y por qué.
- Qué propuestas de IA se aceptaron, modificaron o rechazaron.
- Qué revisión se hizo antes de incorporar el cambio.
- Qué pruebas o comprobaciones se realizaron.
- Qué limitaciones siguen pendientes.

No se debe afirmar que una propuesta fue revisada, comprendida o probada si no se hizo realmente.

## 5. Cómo se revisa código asistido por IA

Antes de aceptar un cambio, comprobar según corresponda:

1. Que resuelve el requisito y no amplía el alcance sin motivo.
2. Que respeta la arquitectura y las convenciones del repositorio.
3. Que no introduce secretos, datos personales ni dependencias innecesarias.
4. Que valida las entradas y controla los errores.
5. Que respeta la autenticación, autorización y propiedad de los datos.
6. Que dispone de pruebas adecuadas.
7. Que la documentación describe el comportamiento real.

Una revisión automática o una respuesta de IA no sustituye las pruebas ni la revisión humana.
